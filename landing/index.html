Pause before you scroll.

Rethink is an Android app that puts a short breathing pause between you and the apps you open without thinking. It also shows where your day went, sets daily limits and keeps focus hours quiet.

    Your day as a clock

    Home is a 24-hour dial. Each tick is an hour, and its length is how long you were on your phone. Tap an hour to see which apps used it.

    On this day the busiest hour was 7 PM: 51 minutes, 83 opens.

    Week and month at a glance

    Switch to Week or Month to see the trend: your heaviest and lightest days, the daily average and how many times you opened an app.

    Every app, ranked

    Each app shows time spent and how many times you opened it. Filter by social, entertainment or productivity, or search for one app.

    The pause

    Turn on Breathe before opening for any app. The next time you open it, Rethink steps in first:

    1. A few slow breaths, timed by the circle.
    2. What brought you here? Bored, putting something off, just habit.
    3. How much time do you need? 5, 10, 15 or 30 minutes.

    When that time runs out, it checks in again. Coming back within a few seconds doesn't count as a new open.

    Limits and focus hours

    Give an app a daily limit, and once it's used up the app stays closed for the rest of the day. Focus schedules mute the apps you choose between set hours, on the days you pick.

    A coach that reads your week

    The coach looks at how you actually used your phone and gives you one mission for today, with a chart of where the minutes went.

    How it's built

    React Native draws the screens. The pause itself is native Kotlin: an accessibility service sees the app coming to the front, and a small pure function decides what happens next.

    Try the decision engine

    Pick a situation. The checks run in the same order as PolicyEngine.decide().

    1. Is it blocked by a limit or focus hours?
    2. Is the pause on for this app?
    3. Is there a session from earlier?
    4. Did you leave more than the grace window ago?
    5. Is the time you asked for used up?

    Pick a situation

    // PolicyEngine.kt: no Android, no I/O. Order matters.
fun decide(
    pkg: String, config: GuardConfig,
    session: Session?, now: Long,
): Decision {
    config.blockRuleFor(pkg, now)
        ?.let { return Decision.Block(pkg, it) }

    if (config.interventionRuleFor(pkg, now) == null)
        return Decision.Allow(NOT_GUARDED)

    if (session == null) return Decision.Gate(pkg)

    val graceMs = maxOf(config.gate.graceSeconds * 1000L, MIN_GRACE_MS)
    if (!session.isOpen && now - session.leftAt > graceMs)
        return Decision.Gate(pkg)

    if (session.isExhausted) return Decision.Shield(pkg)

    return Decision.Allow(
        if (session.isOpen) ACTIVE_SESSION else WITHIN_GRACE)
}
    Screens
    React Native 0.83 and TypeScript, React Navigation, SVG charts, a small motion kit for entrances and presses.
    Native Android
    Kotlin AccessibilityService, Jetpack Compose for the pause screen, UsageStatsManager for screen time, background fetch.
    Bridge
    Typed native modules. JS pushes the rules to Kotlin on every change and drains outcome events back, so the pause works even when the JS side is asleep.
    Backend
    Node and Express on Vercel, Supabase for accounts and data, Gemini through LangChain for the coach.
    Tests
    33 JVM unit tests on the decision engine, the app-switch filter, the pause content and the screen-time math.
    Privacy
    The accessibility service only listens for window changes and has canRetrieveWindowContent="false". It can't read anything on your screen.

    Installing

    1. Download the APK on your Android phone and open it.
    2. If Android asks, allow your browser to install apps.
    3. Open Rethink and give it Usage access so it can show your screen time.
    4. To use the pause, turn on the Rethink accessibility service when the app asks.

    Why it asks for these

    Usage access
    Reads how long each app was open and how often. This feeds the dial, the weekly views and the coach.
    Accessibility service
    Tells Rethink which app just came to the front, so the pause can appear before it. It can't see or read what's on screen.
